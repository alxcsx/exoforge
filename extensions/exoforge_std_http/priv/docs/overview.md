# HTTP transport

The REST transport on port 4001, with OpenAPI routes derived from the service contracts and the CORS settings.

## Actions

| Action | Scope | Takes | What it does |
|---|---|---|---|
| `status` | `global` | - | Returns HTTP server status and registered route summaries. |

## Events

It declares no events.

## Settings

It reads no settings.

## Data

It creates no tables of its own.
