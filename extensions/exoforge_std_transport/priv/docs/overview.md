# Transport gateway

The gateway behind `ws` and `http`: framing, dispatch to the kernel, and the game-version check at sign-in.

## Actions

| Action | Scope | Takes | What it does |
|---|---|---|---|
| `status` | `global` | - | Returns transport layer status. |

## Events

It declares no events.

## Settings

It reads no settings.

## Data

It creates no tables of its own.
